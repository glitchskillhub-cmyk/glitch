Full Syllabus

What you'll build across 45 days.

A hands-on curriculum built around practical implementation, not passive content delivery.

Module 1 — Web Foundations
HTML · CSS · Responsive Design
Week 1
▾
HTML5 semantic structure and document hierarchy
CSS layout systems — Flexbox and Grid
Responsive Design and mobile-first patterns
Why this matters: Even backend engineers interact with frontend projects in team workflows. Building a solid foundation prevents integration delays and improves code review participation.
Module 2 — JavaScript and ES6+
Core JS · Modern Syntax · Async Patterns
Week 1–2
▾
JavaScript fundamentals and execution model
ES6+ syntax — destructuring, arrow functions, modules, spread
Promises, async/await, error handling patterns
Closures, scope, and practical function design
Why this matters: JavaScript is the language of Node.js. A strong command of modern JS patterns directly affects API code quality, maintainability, and interview performance.
Module 3 — Advanced Node.js
Event Loop · Streams · Performance
Week 2–3
▾
Node.js architecture and the Event Loop in depth
Streams and Buffer handling
Node.js performance concepts and non-blocking I/O
Module system and dependency management
Why this matters: Senior backend engineers are expected to understand what happens under the hood. Event loop questions and performance debugging come up in almost every backend interview at mid to senior level.
Module 4 — REST API Development
API Design · Authentication · JWT · RBAC
Week 3–4
▾
REST API design principles and standards
Authentication patterns and session management
JWT — generation, validation, refresh strategy
Role-Based Access Control implementation
Middleware architecture and error handling
Why this matters: REST API development and authentication implementation are core to every backend engineering role. JWT and RBAC are standard requirements in most production systems.
Module 5 — PostgreSQL
Database Design · Joins · Optimisation
Week 4–5
▾
Relational database design and schema planning
Complex SQL joins and aggregate queries
Database performance optimisation and indexing
PostgreSQL integration with Node.js applications
Why this matters: PostgreSQL is the preferred database in many production environments. Engineers who can write optimised queries and understand schema trade-offs are significantly more valuable to teams.
Module 6 — GitHub and Team Workflows
Version Control · Collaboration · Code Review
Week 5
▾
Git internals — commits, branches, merges, rebases
GitHub team workflows and pull request practices
Code review participation and version control hygiene
Portfolio project structuring on GitHub
Why this matters: Every engineering team uses Git. A clean, well-documented GitHub profile with real project work is one of the strongest signals you can send to potential employers.
Module 7 — TypeScript
Type Safety · Scalable Code Patterns
Week 6
▾
TypeScript fundamentals and type system
Interfaces, generics, and utility types
Clean and scalable coding patterns in TypeScript
Integrating TypeScript into Node.js projects
Why this matters: TypeScript adoption in production Node.js codebases has grown substantially. Most new backend projects at scale now use TypeScript. It is increasingly a baseline expectation in senior role job descriptions.
Module 8 — Docker and Deployment
Containerisation · Deployment Basics
Week 6
▾
Docker concepts — images, containers, and volumes
Containerising Node.js applications
Deployment basics and environment configuration
Why this matters: Containerisation is now standard in professional engineering teams. Understanding Docker gives you the ability to participate meaningfully in deployment discussions and CI/CD workflows.
Module 9 — Real-Time Projects and Mock Interviews
Capstone Projects · Portfolio · Interview Prep
Week 6–7
▾
Full project implementation using the complete stack
Portfolio project review and GitHub documentation
Mock interview sessions — technical and practical
LinkedIn and Naukri profile optimisation guidance
Why this matters: Real implementation that ships is how you demonstrate competence. Mock interviews prepare you for the specific types of questions backend engineers face in real interview settings.
